# About Me

This folder contains parts needing to be ordered. Each file represents an indivigual date and time. The summary.txt file contains a overview of all the open calls at any given time in a human readable format.

## Formatting

The formatting of each csv file is in the following:

_customer;part number;description;quantity needed;reason for needing part_

## Summary file

The summary file is autogenerated every hour on the hour via standard GNU crontab implementation.
